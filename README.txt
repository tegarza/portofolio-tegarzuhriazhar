PORTOFOLIO TEGAR ZUHRI AZHAR
============================
Isi folder:
  index.html     halaman utama
  css/style.css  tampilan
  js/main.js     animasi dan interaksi
  images/        logo, ijazah, sertifikat, dan penghargaan

Cara memakai:
1. Buka index.html di browser (butuh internet karena GSAP, Lenis, Motion, dan font dimuat dari CDN).
2. Foto profil: simpan file foto Anda dengan nama  images/foto-profil.jpg  (rasio 3:4 paling pas).
   Sebelum file itu ada, halaman menampilkan kotak placeholder.
3. Untuk online gratis: upload seluruh folder ke Netlify Drop, Vercel, GitHub Pages, atau Cloudflare Pages.

Catatan privasi: nomor NIK pada ijazah S1 sudah diburamkan. Dokumen lain masih memuat NISN dan nomor induk,
jadi pertimbangkan untuk memburamkannya juga sebelum dipublikasikan.
